2026-11-12 23:00 主人拍板的产品逻辑。这是 Snug 的核心功能，第三阶段照这个做。

- **可选、不强制**：Snug 是 UU 的增强，不替用户做决定。手机连上后，一切先和原版 UU 一模一样：原来的屏照常显示，手势也是原版的。
- **多出一块竖屏**：手机或平板控制端连上时，Snug 自动加一块「Snug 手机屏」（竖屏 540x950pt，2 倍高清），UU 的屏幕列表里就多出这一项。不切过去就不影响任何东西。电脑控制端连上时不加。
- **窗口列表**：手机屏空着时，显示 Snug 自己的窗口列表，Mac 上开着的窗口排成大卡片，像 iPhone 的多任务界面。点哪张卡片，哪个窗口就被「吸」过来：铺满屏幕，字号按这个 App 记住的级数放大（默认 2 级），手势换成 iPhone 那套。被吸过来的窗口会暂时从原来的屏上消失。
- **随时切换**：底部有一条 iPhone 那样的小横条，往上滑回到窗口列表。点另一张卡片，新窗口吸过来，旧窗口回原位、字号缩回。列表里还有：放回去、横过来 / 竖回去、字大、字小。
- **横屏（方案 1）**：UU 里始终只多一块屏，默认竖屏，列表里放一个「横过来」开关。不同时加两块屏，也不自动跟手机转向（主人：「就按 1 做，方便，也干净」）。
- **切回原来的屏**：和原版 UU 完全一样，手机屏上的窗口留在那里等你回来。
- **断开 UU**：窗口回原位、字号缩回、手机屏消失，Mac 上不留痕迹。
- **Mac 零操作**：装好、授一次辅助功能权限、开机自启，之后不用再管。设置页只有一个总开关和几项微调。菜单栏图标只用来看状态、打开设置和退出，不再是操作入口。
- **删掉原版那套**：原版「设主屏 + 关物理屏」整套删掉，包括虚拟屏引擎、熄屏保护、看门狗、救急工具、设备表、模拟压测。

**Why:** 主人原话：「做产品肯定不能这么繁琐……像 uuyc 它背后很复杂，但对用户来说几乎无感」「snug 对于用户来说是可选的，而不是强制的……一开始都是完全和没动过的 uu 一样……uu 会多出一块可以切换的竖屏，然后用户可以选择把哪块屏幕吸过去用，以及随时切换」「我们一定要有隔离的思维，要做的干净」。

**How to apply:** 设计任何交互都先问三件事：用户是不是只在手机上就能完成？没用到手机屏时是不是和原版 UU 完全一样？Snug 的改动是不是都限定在手机屏上，并且能还原？技术事实见 [[project-phone-screen]]，协作偏好见 [[feedback-product-thinking]]。
