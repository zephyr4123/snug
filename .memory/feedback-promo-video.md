Snug 的宣传片在 `~/coding/personal/kineto`（Remotion）里做，由那边的会话动手；这边提供产品事实、核对画面里的交互。

**Why:** 2026-11-13 定第一支时主人连续纠正：建议的实机演示被否（「实机演示的效果远没有代码画出来的效果好」），叙事化的骨架也被否（「这东西不是来讲故事、不是来煽情的」）。转达方向给 kineto 时，主人又叮嘱「千万不要把对面给锁死了」。

**How to apply:**
- 风格是产品发布会：直接摆痛点、给答案，快推快切，配快节奏的 funk 或 phonk；不讲故事，不铺垫
- 受众是大众，技术点到「手机终端里敲 claude」为止
- 画面以代码画为主，真截图只贴在旁边当配角，因为截图是静态的、动不起来
- 宣传片和 README 划清界限：场景可以演绎（电脑在宿舍、人在外面），不必守 README 的真实感；但界面细节必须真，iOS 键盘、App、图标都照真的画，不乱编
- 字幕书面语、短词短句，不写主谓宾的陈述句（「我觉得……」在发布会上掉档次）
- 给 kineto 只传方向、硬约束和产品事实，留出开放区间，不给逐镜头脚本，也不给现成文案让它照抄
- 配乐由主人自己指定，不提授权
