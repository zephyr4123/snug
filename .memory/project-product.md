**目标**（2026-11-12 主人定）：让用手机通过 UU远程 使用 Mac 的体感最好，往清晰、大、方便做。虚拟屏只是手段。

**形态**（11-12 拍板，11-13 定稿，2.0.0 即此形态）：
- 手机或平板连上时多出一块竖屏「Snug 手机屏」；不切过去，一切和原版 UU 一样。控制端是电脑时不加
- 屏上是窗口列表，点哪个窗口就放上来铺满、字号放大；底部指示条回到列表，换窗口时旧窗口归位；断开后全部还原、手机屏移除
- Mac 零操作：装好、授一次权限、开机自启；菜单栏只看状态、开设置、退出

**已拍板的取舍**（别走回头路）：
- 只有竖屏：横竖切换要换一块屏，UU 会丢掉选中的屏、跳回第一块，11-13 砍掉（主人：「这里得做减法」）。之后不加会换屏的功能
- 原版「设主屏 + 关物理屏」整套删除：改主屏会让 macOS 重排窗口和菜单栏，把 UU 搅乱
- 键盘遮挡不做：UU 弹键盘时把手机上最后点的位置推到键盘上方，Mac 收不到任何键盘信号；「先点输入行、再弹键盘」就够用
- macOS 自带的缩放无效：UU 抓的是放大前的画面
- 列表交互：放着窗口时左上角显示「‹ App 名」返回键，没有就不显示；打开窗口时整屏显示「正在打开」；列表露着时卡片不换位置
- **屏幕适配**（11-14 拍板）：App 限定了最小尺寸时，手机屏换成刚好装得下的一档（等比、最宽 1080），窗口照样铺满、字跟着小，手机上双指放大。按窗口实测选档、不按 App 预设；不做左右平移。主人看过 740 那档「有点偏小」，仍选这条：通用、不用一个个填坑

**How to apply:** 设计任何交互先问三件事：只用手机能不能完成？没用手机屏时是不是和原版 UU 一样？改动是不是只限手机屏、并且能还原？协作偏好见 [[feedback-product-thinking]]，实现上的坑见 [[project-phone-screen]]。
