1. **图标只用 SF Symbols**，不自己画（菜单栏图标、小横条这类小元素也一样）；设置行、步骤、按钮都配系统图标，页面不能只有文字。App 图标除外
2. **文字精简、书面、克制**：能用短词就不用完整陈述句，句末不加句号（「等待连接」「手机屏已就绪」）；不用口语（「还原」而不是「放回原处」，「稍后」而不是「稍后再说」）
3. **每个状态都讲清楚**：空的、加载中、出错都要一眼看懂。耗时动作要有加载动画；出错写明哪个 App、出了什么事、接下来怎么办，不用技术词；能返回的地方给醒目的返回键，不能返回就不显示

**Why:** 主人原话：「官方库质量非常高，设计统一又好看」「用的语言得要书面语，得要非常冷静克制」「苹果有一个很重要的设计原则：每一个状态都要讲清楚」。

**How to apply:** 界面文案先写出来再砍一半；每加一个元素先找 SF Symbols 有没有对应的。日志和代码注释不受此约束。相关：[[feedback-product-thinking]]、[[feedback-doc-writing]]。
