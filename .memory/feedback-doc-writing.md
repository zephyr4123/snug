对外文案（README、Release 说明、GitHub 简介、官网）一律书面语，措辞正式、凝练。主人说的是想法和方向，写进文档要提炼、重组、打磨，不照着原话抄。

**Why:** 2026-11-13 改 README 时被连续纠正：「太口语化了」「我只是跟你交流我的想法而已，并不是让你照着我的原话去抄」。致谢 UU远程 那段改了三版：照抄太单薄 → 加强了但口语 → 书面语才过。

**How to apply:**
- 先把主人的话拆成要点，每个要点讲出分量（比如高质量为什么是门槛），再用书面语重写；口语词换掉（「跟手」→「响应灵敏」）
- 能分点就分点，少大段文字；少量 emoji 只放标题；README 是门面，技术细节放 docs/
- 图文对应：图放在它说明的那一步旁边；单独的图前面先用一句话点题
- 截图、录屏打码只糊必要的一小块（个人信息、文件链接），不整片糊（主人：「全都糊成一片看啥」）；主人说不介意的内容就不打
